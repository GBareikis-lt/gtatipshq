# Instagram carousel backgrounds

Put slide background photos here, one folder per carousel, matching the paths in
your `content/ig/<name>.json` spec.

```
assets/ig/
  gta6-by-the-numbers/
    01.jpg
    02.jpg
    …
```

Missing files fall back to a solid brand color, so you can render and preview a
carousel before sourcing the images.

Good sources: official GTA 6 trailer screenshots, press-kit art, or AI-rendered
Vice City / Leonida scenes. Cropped to cover the top of each slide.
